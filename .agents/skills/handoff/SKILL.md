# 交接更新

每次停下前做，和代码一起提交到当前分支。

## STATUS.md（只写当前正确的状态）

- 更新时间（UTC）和谁更新的。
- 当前目标：一句话。
- 现状：做到哪了，在哪个分支 / PR。
- 等 lan 定的事（没有就删掉这一节）。
- 下一步：一件具体的事。
- 验收步骤：lan 在 Windows 上做的 1–3 步。

已经不成立的内容直接删，不留“之前的方案”。

## HANDOFF.md

- 上一位停在哪：分支、PR、做到第几步、哪里没验证。
- 背景：只留仍然成立、新 agent 不知道就会走弯路的事实。
- 注意：坑和还没解决的问题。

写完自己读一遍：一个从没见过这个项目的 agent，只读 `AGENTS.md`、`STATUS.md`、`HANDOFF.md`，能不能马上开工？
