# 先找现成的

1. 在 GitHub 搜关键词（中英文都搜），看星数、最近提交、许可证。先看 [参考仓库调查](https://claude.ai/code/artifact/25befcb0-c4db-4927-a29b-cc459951d1ba) 有没有已经查过的。
2. 读源码确认功能真的存在，不只看 README。记下文件、函数和固定提交链接。
3. 判断：
   - 许可证：MIT / Apache / BSD 可以复制，保留版权声明；AGPL、CC BY-NC-SA、没有许可证文件的只借思路，不复制代码。
   - 能否在 Windows 上跑；依赖有多重。
   - 直接用、少量改、只借思路，三选一，写一句理由。
4. 把结论写进工单的“当前状态”。没找到合适的，也写一句“查过哪些、为什么不用”。
