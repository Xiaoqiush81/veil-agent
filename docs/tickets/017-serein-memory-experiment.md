# 工单 017：Serein 与 Ombre 独立记忆质量实验

## 目标

lan 打开一份中文实验报告，就能对照两套系统对同一组 Peter/Ghost 虚构经历的自动保存、跨窗口回忆、原话证据、错误和费用，再判断 Serein 是否值得替换 Ombre。

## 当前状态

Windows 端到端虚构数据实验已完成，中文结果见 [`docs/reports/017-serein-vs-ombre.md`](../reports/017-serein-vs-ombre.md)。基线为 main `580c420ce1f10a2525427d6cd61166903860a5e3`；Serein 固定提交 `6b4ee499d3efc69ad646783c069c95f4dc24e438`，Ombre 固定提交见 `docs/ombre-005-compatibility.md`。样例、盲测、两角色隔离库、结果、生命周期 canary 均与 016 lab 和正式数据隔离。

主实验加生命周期检查共 43 次付费请求，实际 ¥0.40328376；免费 embedding/rerank 1,061 次。预算代理在每个外发收费请求前预留，硬上限 ¥9.99/120 次付费请求和 1,200 次免费调用。没有读取或修改正式 Peter/Ghost 记忆、人设或日常服务。7 项预算代理测试通过。Serein Peter Event 保存较完整且绑定 20 条原话证据，但 6 个可回答盲测问题只召回 1 个；Ghost Event 漏掉天文夜安排。Ombre 本次自动补记没有生成条目。生命周期限制和未验证范围以报告为准。

结论是证据不足，当前不替换正式 Ombre。任何复跑会重新调用模型并产生费用；必须继续使用既有账本，不可清账后绕过硬上限。API key 仅由用户本机环境提供，不写入仓库和报告。

## 验收步骤

1. 打开最终中文报告，查看同一段 Peter 经历的原始摘要、两套自动保存内容和相同盲测题的实际回答及证据。
2. 查看 Peter/Ghost 隔离、事实更新、闲聊误存、编造、隐藏/删除/重启/整理的逐项结果，以及模型调用和费用。
3. 按报告中的 Windows 复跑步骤检查隔离实验目录；报告明确列出未运行或不支持的能力，不以单元测试替代体验结论。

验收报告明确结论为“证据不足，不替换正式 Ombre”；本工单不实施迁移或更改日常记忆行为。
