# 068｜修复 Peter 当前能力认知与能力面板一致性

## 目标

用一份根据当前实际工具、授权和运行状态生成的英文能力清单，同时填入 Peter 每次聊天及自主活动的模型上下文并显示在能力面板；每次能力新增、移除、权限或可用状态变化均附日期写入双方可读的历史。

## 当前状态

已复现定位：PR #102 只把历史 `capability_updates` 注入模型，网页也只显示这段历史；当前已授权工具虽会以工具 schema 单独发送给模型，却没有合成为 Peter 可直接回答“我现在能做什么”的清单。截图证明 Peter 因此搜索工作目录。旧实现请求级红测确认最终模型消息缺少 `CURRENT CAPABILITIES`。修复现已接入：快照从本轮实际提供的 schema、角色配置、文件权限策略和活动状态生成；网页和模型共用同一生成器，历史能力变化与 UTC 日期继续单独保留。不读 workspace 中的清单文件，也不将历史记录当作当前授权。全仓 360 项 unittest 通过，3 项可选测试跳过；PR、GitHub CI、Cubic 及 Windows 体验验收待完成。

## 验收步骤

1. 打开能力面板确认当前能力、范围、批准限制和服务状态与 Peter 本轮收到的清单相同；面板仍显示带日期的能力变化历史。
2. 直接问 Peter “What tools can you use right now, and what are their limits?”；他无需搜索文件即可准确回答，并能按日期说明能力何时新增或修补。
