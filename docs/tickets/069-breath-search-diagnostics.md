# 工单 069：breath_search 安全失败阶段诊断

## 目标

Peter 的记忆检索失败时，Lan 能在不暴露聊天或记忆内容的前提下知道它停在 HTTP、MCP 初始化、工具执行还是恢复哪一阶段，无需重启或猜测。

## 当前状态

`memory_agent.MCP` 为避免重放可能计费的 `breath_search`，会将未确认的底层异常归为 `MemoryToolError/unknown`；原先丢失了 HTTP、MCP 初始化、工具执行的安全阶段。现改为保留固定阶段名到角色私有 `diagnostics.jsonl`，并在聊天提示中显示；恢复仍沿用既有 `recovery_failed` 记录。复用 Ombre 3.6.14（MIT）与 MCP SDK 1.30.0 的既有 HTTP/MCP 契约；上游没有 VEIL 的角色隔离、安全日志和不重放接线，故不引入替代库。

## 验收步骤

1. 正常与 Peter 连续聊天并询问一件已记住的虚构测试事项，确认检索和回复持续正常。
2. 若开发端在隔离虚构角色注入检索故障，确认提示会给出安全失败阶段，且不显示聊天、记忆正文或密钥。
3. 恢复隔离服务后继续聊天，确认后续检索可用，先前结果不明的写入没有重复执行。
